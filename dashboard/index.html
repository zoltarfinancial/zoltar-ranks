Primary objective

Given a rank produced at time T, when should the buy happen?

Everything else in this console exists to make the answer to that question trustworthy — and to make it obvious when it isn't.

04 — Signal quality

Where the signal actually lives

Information Coefficient is the rank correlation between score and realized forward return — a measure of the signal itself, independent of any trading rule. It has ~1,200 symbols × ~230 days behind it, so it detects effects a portfolio-level test never could.

06 — Pre-registration

Hypothesis register

Every experiment is registered here before it runs, with its success criterion. Rejected hypotheses stay — the row count is the denominator for the false-discovery-rate correction. Click a row for the reasoning and what we learned.

09 — Active build · progress

What Claude Code is building, and how far in it is

One row per phase of the build plan. Open a row for its deliverables — the concrete files that have to exist before the phase can be called done. A phase is only done when every deliverable under it is checked and its contract gate passes.

10 — Active build · integrity

Contract gates

Assertions that must hold for any result on this page to mean anything. The rule is stop, not loosen: a failing blocker gate invalidates every number downstream of it until the cause is found. Gates that have never run are as informative as gates that fail.
